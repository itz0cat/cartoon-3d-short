# Kenney models (CC0) go here

world.ts loads `public/bridge/kenney/<name>.glb`. Missing files are skipped (the render still works, the props just
do not appear). Download the free kits from https://kenney.nl/assets (Nature Kit, Fantasy Town Kit and similar),
copy the GLB files out of the zip, rename them to the names below and commit them.
Only the ones you need; each is small (KB range).
